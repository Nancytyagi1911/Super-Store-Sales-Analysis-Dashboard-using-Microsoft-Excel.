🛒 Super Store Sales Analysis (Excel Dashboard)

This project focuses on analyzing Super Store sales data using Microsoft Excel to generate business insights. The dataset contains information about orders, customers, sales, profit, and product categories.

The goal of this project is to transform raw data into meaningful insights using data cleaning, pivot tables, and an interactive Excel dashboard.

📊 Project Objectives

Clean and prepare raw sales data

Analyze sales and profit trends

Identify top-performing product categories

Evaluate regional sales performance

Create an interactive Excel dashboard for business insights

🛠 Tools & Skills Used
